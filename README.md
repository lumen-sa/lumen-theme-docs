# LUMEN Signature — Theme Guide

Public setup guide (Arabic and English) for the **LUMEN Signature** theme for Salla stores.

- Page: `index.html` (a single static page; the language switch is `#ar` / `#en`).
- Hosting: GitHub Pages from the repository root. `.nojekyll` serves the files as they are.

This repository contains documentation only: no theme source code.
